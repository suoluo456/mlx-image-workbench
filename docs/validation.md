# 0.1.0 发布验证

验证日期：2026-10-26。首版仅面向 Apple Silicon、macOS 26 或更新系统。

## 已完成

- 独立源码目录、独立 Python 环境和缓存、独立数据目录；默认端口 7866。
- 对迁移时读取的 36 个原始源文件进行 SHA256 前后比对，原文件未改动。
- 新环境中的 31 项 Python 测试通过：下载续传、哈希校验、同长度损坏、磁盘不足、目录保护、模型依赖、历史保留、网页健康检查、本机访问限制、可选酒馆开关、LoRA 拒绝、参考图及独立模型索引。
- 15 项酒馆扩展 Node 测试通过：服务连接、导入工作流、保留/恢复原设置、错误不覆盖设置、分镜隔离及通用人物规则。
- 用独立的最小网页环境启动 7866 服务并实际打开浏览器：只有两个基础模型，未下载时不可生成；酒馆默认关闭；历史记录为 0；页面未显示 LoRA。
- `.command` 的 AppleScript 弹窗可编译，Shell 和前端 JavaScript 语法检查通过。
- Release ZIP 经 macOS 自带 `ditto` 解压，四个中文 `.command` 入口均保持 `755` 执行权限；带中文和空格的新目录能正确提示先安装环境。
- 三个模型组件源各实际下载一个固定版本的小文件，大小及 SHA256 均匹配；Turbo 的旧版本已失效，已改用内容哈希相同的可用固定版本，并重算转换后文件的校验值。
- 无系统 Python 的引导链通过：从官方 PyPI 下载并校验 uv，由它联网安装项目私有 Python 3.12.13；在 PATH 仅包含系统工具目录时完成安装入口验证。
- 基础环境的固定依赖安装与依赖检查通过。网络下载大包超时后，将准确版本的公共安装缓存只读克隆至新缓存，核验 23,197 个文件哈希，再由私有 uv 安装新环境；没有复制原虚拟环境。参考环境在修正 Pillow 版本冲突后通过依赖解析。
- 启动器的准备等待、同一实例复用、模型目录变化时拒绝误复用、停止与端口释放通过。
- 两个模型均在新主环境完成真实推理，使用已逐文件校验的公开权重 APFS 临时副本，输出和日志仅保存在隔离测试目录。每次运行前检查可用内存，进程结束后正常退出。

- 发布使用明确文件清单，拒绝用户数据目录、符号链接、大文件及明显凭据；检查源码中的旧个人角色名和本机路径，无匹配。

## 验证边界

测试没有访问原有工作台服务、读取旧历史或复用旧 Python 环境。

尚未在另一台全新 Mac 上下载全部模型并完成真实生成；没有把既有环境的历史出图记录算作公开版验收。本次依赖使用暖缓存、模型使用独立权重副本，因此不能算作 24 GB / 11 GB 模型的全量网络冷下载测试。

尚未在干净安装的 SillyTavern 中完成真实漫画生成。扩展接口已对照官方代码，并通过独立单元测试；第三方酒馆版本或定制扩展仍可能影响兼容性。

未进行 Apple Developer ID 签名、公证或从互联网下载后的 Gatekeeper 真机放行验收。ZIP 的 Unix 执行权限与 macOS 安全放行是两个独立环节，首次打开可能需要系统确认。

因此 0.1.0 以预览版发布。稳定版还需要补齐新机器上的完整安装与真实生图验证，以及下载后的首次打开验证。
